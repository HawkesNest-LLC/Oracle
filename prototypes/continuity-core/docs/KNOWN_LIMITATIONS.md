# Known Limitations, v0.1

1. No deployed HTTPS URL or remotely accessible iPhone preview. A downloadable single-file offline demonstration is provided.
2. Scene geometry is a 2D interactive schematic, not React/Three.js 3D. Mobile Safari/Chrome/iPad device tests have not been run.
3. SQLite is used for the local proof. The PostgreSQL migration has not been applied to a live PostgreSQL instance.
4. The reference HTTP API disables canon promotion. Production Creator authentication and authorization remain unimplemented.
5. Original Voyager 2371 arrival manuscript is missing from the inspected source set. The console correctly returns UNKNOWN.
6. Full source corpus ingestion, provenance at line-offset level, rights classification, and signed custody are not implemented.
7. Hash-chained simulation events are not independently anchored and are not tamperproof against a privileged attacker.
8. Offline HTML uses curated static claims and localStorage; it does not synchronize to the backend database.
9. The visual impact graph is a small illustrative relationship view, not yet a complete interactive dependency debugger with automated propagation.
10. No NPCs, autonomous activity, background scheduler, trajectories, or persistent Jupiter Station world exist in this prototype.
11. A GitHub PR is a review artifact, not evidence that another AI system has inspected or accepted the code.
