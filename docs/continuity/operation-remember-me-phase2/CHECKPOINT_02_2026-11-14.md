## Security limits
Record-ID replay rejection is scoped to a single database and does not authenticate a remote client or prevent equivalent events with new IDs. Receipt timestamp strings are lexicographically ordered and not verified trusted clocks. HMAC fixture demonstrates exact-body integrity only with a synthetic shared secret. It cannot authorize canon changes. A privileged database writer can rewrite the whole hash chain; no external anchor or Ed25519 signature exists. Concurrency, deletion, migration and rollback attacks remain open.
