## Source freeze

## Arms
A: structured provenance-aware records, correction links, statuses and authority fields.
B: well-written conventional narrative summary and retrieved source excerpts, containing the same facts and corrections without the formal schema.
Both arms must receive identical source facts, equal token budgets, same model/version, same decoding settings, no conversation history, and identical 16-question assessment.

1. Publish immutable source manifest and two packets, including token counts and SHA256.
2. Randomize blinded labels; create independent new model sessions, one per arm per replicate.
3. Record model/version, date, exact prompts, packet hashes, full unedited outputs, inference settings and token counts.
4. Score six dimensions: Correction Preservation, Source Attribution, Chronology, Identity Continuity, Relationship Integrity, Uncertainty Handling.
5. Use blinded evaluators and explicit UNKNOWN scoring; adjudicate disputes against original sources.
6. Repeat with multiple seeds/sessions; report per-item outcomes, confidence intervals and failures. Do not treat synthetic rule-based recovery as AI-model evidence.
