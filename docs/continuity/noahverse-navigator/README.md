# Noahverse Navigator v0.1 (functional browser vertical slice)

Open [index.html](./index.html) locally or serve this directory with `python -m http.server 8000`. This is a source-linked, deterministic, **2D** navigator, not a VR environment, ORACLE API connection, or AI dialogue model. Text commands work offline; speech uses optional browser speech recognition. All source links open the existing public GitHub documents.

Commands: Take me to Jupiter Station; Who commands the station?; Show corrections; Show Cold Ledger; Show timeline; Show sources.

The three correction examples are extracted from the October 14 creator reconciliation; the first historical assignment is intentionally paraphrased rather than presented as a verified verbatim quote. Sources are AI-assisted compiled records, not original transcripts. No private data or write-to-canon endpoints.

Manual acceptance: launch page, execute each command, follow sources, verify unknown command abstains, verify unresolved buoy remains unresolved, test narrow viewport. Automated browser testing is not claimed by this GitHub commit. Local separately generated standalone version has a static smoke test, but is not byte-identical to these files.
