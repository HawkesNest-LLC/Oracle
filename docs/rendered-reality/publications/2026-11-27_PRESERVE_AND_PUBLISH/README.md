## Current scientific distinctions
1. **Source occurrence versus authorship:** A human user transporting AI text does not originate that text; repeated relays are not independent validation.
2. **Historical state versus current state:** Corrections remain linked to superseded claims without silently treating old assertions as current.
3. **Historical acceptance versus current authorization:** A recorded prior acceptance is not a continuing grant. Key-revocation ordering and permission freshness are different questions.
4. **Integrity versus truth:** A matching hash validates bytes against a selected reference, not factual truth, source completeness, personal identity, or lawful consent.
5. **Simulation versus scientific result:** A fictional NPC behaving independently does not demonstrate consciousness or human survival.
6. **Intention versus execution:** A remembered task, output outline or verbal claim is not a completed artifact. Completion requires independently inspectable receipts.
