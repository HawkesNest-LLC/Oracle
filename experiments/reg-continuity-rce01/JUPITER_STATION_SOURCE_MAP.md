## Scope and public-privacy protection

No private real-world family chronology, medical data, email, personal addresses, or unpublished manuscript passages were used as fixtures. Real human names occur only as existing fictional character labels and author/provenance markers in creator-released canon records. No future narrative event is authorized merely because a simulator generated it.

## Distinguish canon from evidence of software

The source texts govern what is true **inside the fictional case**. The receipts (`npm test` outputs, repository commits, API responses, and actually stored files) govern what is implemented **in the real experiment**. Neither category can substitute for the other.
